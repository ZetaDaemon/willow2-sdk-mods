# Inventory Saver
Saves items in your inventory and bank, including custom parts.

If an item is unable to be loaded in (usually do to the mod not being running), the item is backed up and a warning is presented giving you the option to return to the main menu, continue playing, or continue playing and purge backups.  
Both the warning and item protection can be disabled.

Additionally allows for refreshing vendors on map load and deleting modded ground items on map transition to prevent broken items.

## Sanity Saver
Inventory saver is designed as a replacement for sanity saver, not to be used along side it. Make sure sanity saver is disabled.

Will automatically import items over from santiy saver files where available. As this only happens when loading that character make sure to leave sanity saver installed so they can be imported.

Inventory saver will back up any sanity saver saves but it's highly recommended to create a seperate backup of your sanity saver saves and game saves before switching.

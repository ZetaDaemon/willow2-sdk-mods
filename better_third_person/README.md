# Better Third Person
Improves the functionality of third person with camera customisation.  
Third person aim has a couple options, zoom in while remaining third person, scope in like normal or default zoom in but double click to zoom.  
Also fixes third person weapon aim, this may cause performance issues so it can be disabled.
